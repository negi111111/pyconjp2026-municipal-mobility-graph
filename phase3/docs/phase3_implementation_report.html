SLIDE 04Phase 3 Queryの組み合わせ

リード｜環境条件は既存の類似度・空港・人流と独立に適用し、各条件の基準値と単位をEvidenceへ残して複合検索の説明責任を確保した。

参照都市基準の決め方例

なし検索集合の中央値空港と新幹線の両方 → 各距離がSearch Universe中央値以下
未収録ランキングから分離住居費 → 類似度は返すがrentをHard Factsへ入れない
