リード｜LLMに数値を計算させず、Plannerは意図を分解し、pandasとNetworkXが順位・距離・類似度を計算してEvidenceを返す。

Hard Facts

Soft Knowledge
LLMの説明や一般背景はHard Factsの外側に置き、順位へ戻さない。
